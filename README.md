# 🤖 Personal Research Assistant

An AI-powered research agent that:
- Breaks topics into research questions
- Searches real-time data
- Generates structured insights

---

## 🧠 Features

- Planner (LLM-based question generation)
- Web Search (DuckDuckGo)
- Summarizer (structured output)
- LangSmith tracing
- MLflow experiment tracking (optional)

---

## 🛠 Tech Stack

- Python
- LangChain
- OpenAI
- LangSmith
- MLflow

---

## 🚀 How to Run

```bash
pip install -r requirements.txt
python app.py
